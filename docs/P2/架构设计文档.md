## 项目技术栈
| 层次 | 选择 | 选择理由 |
|------|------|---------|
| 前端框架 | Vue 3 + Vite + Element Plus + Pinia + Vue Router | 响应式组件化设计，SFC 模板语法清晰；Element Plus 提供高质量桌面端交互组件；Pinia 与 Vue Router 提供统一状态管理与路由权限控制 |
| 后端框架 | Spring Boot 3 (Java 17) | 强类型安全与严格枚举控制状态机流转；Spring Security + JWT 内存验签无状态认证；声明式事务（@Transactional）与悲观锁保障资金与抢单强一致性 |
| 数据库 | MySQL 8.0 | 关系型存储，事务 ACID 特性完备，与 Spring Data JPA 高效集成，业务时区统一采用 Asia/Shanghai |
| 缓存与中间件 | 当前无 Redis 依赖（后续演进扩展） | 当前阶段 JWT 维持纯无状态签名，验证码与高频状态直查数据库；引入 Redis 缓存与 Redisson 分布式锁作为后续演进，记录于根目录 `TODO.md` |
| 部署方式 | 桌面端 Web SPA | MVP 阶段聚焦桌面端高交互场景（发布、管理、二维码扫码）；移动端 Native/小程序适配作为后续扩展，记录于根目录 `TODO.md` |

## 架构图

```
┌──────────────────────────────────────┐
│           展示层 (Vue 3)              │
│  Element Plus + Pinia + Vue Router   │
│       (面向桌面端 Web SPA)            │
└──────────────┬───────────────────────┘
               │ RESTful API (JSON over HTTP)
               │ JWT Token 认证 (Authorization: Bearer <token>)
┌──────────────▼───────────────────────┐
│         Controller 层                │
│   Spring MVC (@RestController)       │
│   请求参数校验、权限判定、响应格式化    │
└──────────────┬───────────────────────┘
               │
┌──────────────▼───────────────────────┐
│          Service 层                  │
│   Spring @Service + @Transactional   │
│   订单/任务状态机、信用分体系、支付与结算│
└──────────────┬───────────────────────┘
               │
┌──────────────▼───────────────────────┐
│        Repository 层                 │
│   Spring Data JPA                    │
│   数据持久化、悲观锁查询、命名约定派生查询│
└──────────────┬───────────────────────┘
               │
┌──────────────▼───────────────────────┐
│         数据库 / 持久化层             │
│   MySQL 8.0                          │
│   (Redis 缓存作为后续演进，见 TODO.md) │
└──────────────────────────────────────┘
```

### 分层纪律：
- Controller 层仅负责请求参数校验、用户鉴权透传和响应格式化，不包含任何业务逻辑；
- Service 层集中实现所有业务规则、事务控制与状态机迁移；
- Repository 层仅负责底层数据持久化与行级锁查询；
- 禁止跨层调用，严守架构边界。

## 模块划分

| 模块 | 功能描述 | 涉及技术点 |
|------|---------|-----------|
| 用户管理与认证 | 注册/登录、JWT 无状态认证、个人资料管理、密码修改 | Spring Security + JWT、BCrypt 哈希、Vue 表单 |
| 需求发布与检索 | 需求分类、发布审核、广场列表多维检索、详情查看 | JPA 动态查询、Element Plus 交互表单 |
| 订单流程与状态机 | 需求状态流转（待审 → 发布 → 进行中 → 完成/取消）；订单状态流转（进行中 → 待验收 → 完成/取消） | Java Enum 状态机、行级悲观锁、@Transactional 事务 |
| 单向评价与信用体系 | 需求方对服务方单向评价、7天自动4星好评、100分制信用分计算、每日零点补偿恢复去重调度 | Service 业务规则、Spring @Scheduled 调度器、幂等记录 |
| 支付与人工结算 | 微信 Native / 支付宝当面付真实扫码支付，交付后24h自动验收与1h付款期，管理员线下打款并上传凭证登记流水 | 微信/支付宝官方 SDK、RSA2/AES-GCM、文件上传存储 |
| 即时聊天与消息通知 | 订单状态变更通知、站内信未读统计、订单点对点即时沟通与群聊生命周期两阶段淘汰 | WebSocket / REST 轮询、Spring Data JPA 软删除与归档 |
| 管理员后台与风控 | 用户封禁/解封、需求审批/驳回、财务线下结算核销、违规扣分与申诉仲裁 | 权限隔离（Role.admin）、财务凭证私有归档、统计报表 |
