# 调研方案

项目背景：大学校园中，学生之间存在大量日常互助需求：快递代取、学习辅导、二手物品交换、活动组 队等。目前这些需求散落在微信群、QQ 群、贴吧等平台，信息碎片化、匹配效率低、缺乏信 任机制。 CampusHub 旨在提供一个统一的校园互助服务平台，让学生能够方便地发布需求、发现匹配、建立信任、完成协作。

① 杨佳茵：

Q1：你在校园生活中，最常遇到的、希望有人帮忙解决的“小事”有哪些？

Q2： 你使用过校内的互助群（如微信群、QQ 群）吗？你觉得好用和不好用的地方分别是什么？

Q3：如果提供一个互助服务平台，你最担心的问题是什么？

Q4：平台会设置“信用分”和“评价系统”，你觉得什么样的规则会让你觉得公平？

Q5：什么情况下你会愿意主动在平台上“接单”帮助别人？你希望获得什么样的回报？

Q6：平台上，你觉得用户之间需要“私聊”功能吗？还是只通过平台留言

② 谢梦真：

Q1：你有没有遇到过‘想找人帮忙但一时间不知道找谁’的情况？

（比如快递代取、想找人组队参加比赛、或者求课程的笔记）你最终是如何处理的？

Q2：当你通过微信群、表白墙或贴吧发布/寻找互助信息时，你觉得最让你‘头疼’或者‘浪费时间’的地方是什么？（例如：信息刷屏太快、回复不及时、或者加了好友发现事情已经办完了）

Q3：如果要把你的快递取件码、或者涉及金钱的二手交易交给一个陌生人，你最担心发生什么？什么样的信息（比如：实名认证、同院系标签）会让你更愿意信任对方？

Q4：如果你在平台上看到有人悬赏‘代取快递’或‘求助期末复习’，在什么情况下你愿意伸出援手？是纯粹为了报酬，还是为了积累社交关系、或者是看重平台的某种积分/头衔？

Q5：对于‘校友互助’，你更倾向于它是一个‘办完事就结束’的工具，还是希望能通过这个过程结识志同道合的朋友？你对在互助平台中加入社交功能（如私聊、动态）怎么看？你会愿意使用吗？

③ 李朝阳：

Q1:关于校园互助平台，你认为除了跑腿，失物招领，二手交易等基础功能外还需要什么功能？

Q2：你认为该平台是否需要实名认证，例如通过学号注册与登录？

Q3：你认为该平台是否需要收费，部分收费还是完全收费，若不收费，是否需要添加自愿捐款功能？

Q4：你认为该平台在监管方面应该采取什么措施，例如引入信誉系统之类？

Q5：如果未来该平台成功上线，你个人的使用意愿如何，是否会对该平台提出建议？理由是？

④ 郭怿盈

Q：你有没有用过类似的产品？如果有，你觉得你用过的产品里面有没有很好用或者需要改进的地方？

Q：发布需求后你更能接受系统推荐最合适的人，还是自己筛选？

Q：如果平台有奖励机制，你更希望是现金、积分（可以引入类似于积分银行的机制，如果你的积分高，下次匹配帮手会优先匹配给你）或者是实际福利（比如食堂优惠）？

Q：你更希望互助是一次性交易，还是可以建立长期联系（就是会不会因为一次良好体验而长期找同一个人帮忙）？

Q：如果你遇到被放鸽子或者被骗，你希望平台怎么处理？
