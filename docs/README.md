# CampusHub 文档索引

文档分两类：**Course** 存课程各阶段的历史交付物，**Engineer** 存当前开发使用的架构与契约文档。

## Engineer（开发权威文档）

| 文档 | 内容 |
|---|---|
| [架构文档](Engineer/架构文档.md) | 技术栈、模块划分、依赖图、信息流、前后端调用流程、运行时配置、已知问题 |
| [模块契约](Engineer/模块契约.md) | 模块边界、冻结接口、依赖方向规则、主干专属文件、前后端接缝 |

新成员或 AI 助手接手开发时，先读 Engineer 两份文档，再读根目录 `AGENTS.md` 与 `CONTRIBUTING.md`。

## Course（课程历史文档，只读存档）

| 目录/文件 | 阶段内容 |
|---|---|
| `Course/P0/` | 团队章程、AI 协作契约 |
| `Course/P1/` | 需求调研、用户故事、用例、需求规格说明书 |
| `Course/P2/` | 架构辩论、ADR-1~4、架构设计文档 |
| `Course/P3/` | API 规范文档、ER 图与建表 SQL、类图、完整设计文档、SOLID 检查 |
| `Course/P4/` | 演示说明、Sprint 看板、代码信任度实验报告、AI 协作反思日志 |
| `Course/assets/` | 上述文档引用的图片、功能思维导图 |
| `Course/` 根下各日志 | Bug 修复、调试对决实验等过程记录 |

注意：`Course/P3/API规范文档.md` 虽是课程交付物，但仍是**外部 HTTP API 的权威契约**，受 AGENTS 契约神圣原则保护；模块间内部接口契约见 `Engineer/模块契约.md`。
